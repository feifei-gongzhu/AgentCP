### 实装内容（蓝图 §3 C3 施工要点逐条）

- **队列/租约/工具调用状态视图**：
  - 意图队列（§10.1）：九态中文标签（proposed/queued/running/resolved/blocked/
    awaiting_review/deferred/obsolete/cancelled）+ 四类别标签（collect/investigate/
    verify/revisit）；服务端状态过滤（status 参数）；游标分页累积；
    「resolved 只表示该版本的问题已处理，不代表关联资产已测透」说明在场。
  - 执行尝试与租约（§10.2）：尝试七态中文标签、worker/意图/执行分配/fencing token、
    租约截止时间与**剩余时间展示**（剩余/已过期按读取时刻计算，另显式呈现
    「未提供」与「无法解析」两态，不臆造时间）；过期活跃租约显式 LEASE_EXPIRED
    警示（旧执行不得继续操作，恢复/重派由 Orchestrator 决定）；迟到提交语义说明；
    客户端「仅看活跃与异常」筛选（明示只作用于已加载数据）。
  - 工具调用状态（§10.2）：六态中文标签（planned/running/succeeded/failed/
    **unknown**/cancelled）；unknown 显式呈现为「需关注」卡片（附「先检查外部
    现状再决定重试，不得当作已完成或已失败」「不视作恰好一次」说明）并与
    running 一同置顶；证据引用展示；响应未携带工具调用数据时 not_provided 明示。
- **unknown 与受阻显式呈现**：unknown 工具调用、blocked/awaiting_review/deferred
  意图（警示底色 + 受阻原因 + 恢复条件，DDL TEXT JSON 字符串自动解析）、过期
  活跃租约、interrupted 尝试（恢复备注）均显式标注，不静默。
- **租约剩余时间展示**：见上；另提供「仅重算剩余时间」（本地重渲染不发请求）与
  「刷新数据（重置到第一页）」「开启自动刷新（每 10 秒）」（默认关闭；关闭与
  组件卸载均清理定时器，不留悬挂回调）。
- **§20.2 执行面摘要**：按已加载数据在数据时刻推导的受阻方向/带恢复条件数/
  活跃与过期租约/中断/unknown 调用计数，附边界说明（计数不代表全量；全局运行
  指标全集由 /metrics 提供，模块 F2、「总览」页呈现；漏洞数量不是唯一健康指标）。
- **§3.2 职责边界**：本页只读监控，无暂缓/恢复/取消操作入口（蓝图 §8.2 user
  角色不含 #22–#26）；「受阻不写死固定重试、恢复与重派由协调 AI 决定」说明在场。
- UI 通用规则（蓝图 §9）：501 → 「未实现」+ 负责模块标注；错误 → 错误卡附错误码；
  未知形状 → 显式提示；空态显式；游标分页不静默截断；URL/编号原样展示不改写；
  不使用浏览器存储；中文文案、内联样式带回退值。
