### 2.1 独立验证页（lib/ui/pages/verification.page.mjs，order 60）

- **验证队列（§8.3）**：任务四态中文标签（等待验证/验证进行中/已完成/已被替代）；
  已被替代附 §7.3 续验语义（新证据到来请求续验、新需求另立任务，旧任务不吞掉新需求）。
  每行呈现：待验证判断编号（可点击展开）+ 类型（假设/事实/漏洞）+ 判断修订、
  验证策略及版本、条件快照、预期三版本（状态/证据集/评估纪元，§12.2）、发起方。
- **Manifest（§12.1）**：所审阅证据清单（Manifest）逐行呈现；D1 落地信封携带的
  manifest 详情（成员数/证据集版本/内容哈希）一并展示；未提供显式「未提供」；
  §12.1 语义说明常驻（reviewed_evidence_revision 必须绑定不可变 Manifest，
  单个最大 Event ID 或「读过最新一条」不能替代）。
- **outcome（§8.3/§8.4）**：四态中文标签 + 不夸大详注——supported「在所审阅的证据集
  版本与指定条件内成立，不代表持续存在」、falsified「明确排除当前判断，不等于『历史
  上不存在』」、insufficient「保存缺口，未确认不伪装成已排除」、conflicting
  「review=disputed 并安排仲裁验证」；applied=true/false 分支承载 §12.2 语义
  （未应用意见显式「保留意见、标记需复核，不覆盖新结论」，不静默丢弃）；
  验证者身份与三类验证者类型（独立模型/版本化规则/仲裁，§3.3 Verifier 不要求每次
  都是 LLM）；支持/反对引用可点击展开。
- **等待时长（§20.2 验证队列等待时间）**：pending/in_progress 任务自创建时刻起按
  数据时刻计算「已等待约 X」；优先采用 D1 落地信封的 waiting_ms（服务端数据时刻值），
  缺失时页面自 created_at 推算；无创建时间→「未提供（不臆造时长）」、不可解析→
  「无法解析（原值）」、终态任务不展示；摘要区给出最长已等待与积压提示。
- **验证观察摘要（§20.2）**：状态计数、结论计数、未应用意见警示、边界说明
  （按已加载数据推导不代表全量；全集指标由 /metrics〔F2〕提供；漏洞数量不是唯一
  健康指标）。
- **验证语义与独立性（§8.3/§12/§2.6）**：五件套（待核实判断/条件/原始证据索引/反对
  证据/策略版本）、「仅有严格提示词或发现者的描述不构成验证」、版本不匹配保留意见、
  发现者不能自行确认自己的漏洞（验证身份独立由调用身份和服务权限落实）。
- **按编号展开记录（§11.2 #14）**：待验证判断/支持引用/反对引用编号可点击，手动
  输入展开（Enter 提交、空输入本地拦截），请求携带 project_id。

### 2.2 漏洞台账页（lib/ui/pages/vulnerabilities.page.mjs，order 70）

- **状态与复核状态分列（§8.2）**：三列网格（编号与内容 | 状态 | 复核状态）+ 列头；
  status（疑似/已确认/已证伪/证据不足）与 review（无待办/待复核/存在争议）是两个
  独立字段，分行分列呈现，不合并、不映射；复核非 clear 的行警示底色 + 行内提示
  「依赖检查须看复核标记，不能只看 confirmed（§8.2）」。
- **文案不夸大状态（§8.1/§8.2/§8.4）**：confirmed 标签自带「已确认（限指定条件）」
  限定；台账标题、语义区块常驻「confirmed 只说明在指定条件下得到确认，不代表持续
  存在；环境变化后可要求复核」「『当前不再复现』『历史上不存在』『已修复』不得混用，
  修复状态如需支持应单独记录」「falsified 不等于『历史上不存在』；insufficient 未确认
  不伪装成已排除」「suspected 起即有编号与报告草稿；只有验证通过后才允许标记
  Confirmed」「发现者不能自行确认自己的漏洞（§2.6）——confirmed 只能由验证服务在
  独立验证 supported 且各版本匹配后应用（§8.4/§12.2）」。
- **条件（§8.2/§8.4）**：适用条件逐条呈现（数组与 DDL TEXT JSON 字符串双形态解析）；
  未注明时显式提示「confirmed 只说明在指定条件下得到确认，未注明条件不代表无条件
  成立」；confirmed 行附确认版本（字符串/对象双形态）；判断修订/证据集版本/评估纪元
  三版本字段展示原值（未提供显式「未提供」，不臆造为 0）。
- **证据入口（§19/§11.2 #14）**：漏洞编号、资产编号、证据引用可点击经
  /records/{id}?project_id=… 展开；D2 落地信封的 evidence 计数（支持/反对/共）与
  candidate_groups（附「候选组只用于查找聚合，不替代漏洞身份 §7.3」）一并呈现；
  手动输入展开。
- **台账汇总**：状态与复核状态分别计数（两字段独立统计）；复核非 clear 条目数显式
  警示（§8.2 依赖放行语义）；边界说明（不代表全量）。
- **客户端视图筛选**：复核非 clear / 单一状态 / 全部——只作用于已加载数据并明示
  （#30 服务端过滤参数未冻结，不绑定；刷新/加载更多发起真实请求）。
- 501 / 错误 / 未知形状 / 空态全部显式呈现；项目选择游标分页累积；两页均不使用任何
  浏览器存储机制。
