### 页面功能（规范 §15.1/§15.3 逐条 + 蓝图 §9）

- **项目选择卡**（GET /projects，A1）：自动选择首个项目并以 `?project_id=` 请求快照；
  项目列表跨页游标累积（「加载更多项目」），不静默截断；空列表显式空态且不发快照请求；
  列表 501/错误/未知形状各自显式呈现。
- **快照卡（§15.1 六要素逐项标注）**：快照编号（snapshot_id）、schema 版本、
  **数据截止提交序号（snapshot_commit_seq，加粗独立成行）**、生成时间、投影范围、
  折叠/省略说明及展开入口；§15.2 订阅边界四元组（subscription_id/subscription_revision/
  resume_cursor）随快照展示，并固定说明「快照之后的增量从 resume_cursor 指向的边界之后
  重放，不漏消息（§15.2）；异步投影以其已处理提交序号为边界，不代表数据库当前版本
  （§15.1）」。
- **折叠（§15.3）**：快照信封 folding_notes 与内容内的折叠块（带 count 的描述符）均渲染
  为「已折叠 N 项 · 原因」+ 按编号展开入口（refs → /records/{id}）；无编号入口的折叠块
  显式说明「折叠只影响展示，全部记录仍保存在库中，可按编号读取」；固定说明「折叠只影响
  展示：折叠节点仍参与依赖、范围、订阅和恢复检查（§15.3）」。
- **投影内容渲染（不改写、不清洗）**：防御式通用渲染器——对象=分组（已知键中文标签，
  未知键原样展示不臆造语义）、数组=卡片/清单、标量原样；层级过深时显式退化为原始 JSON
  展示（不静默截断）；URL/路径逐字原样展示（不小写、不解码、不重排、不拆分），状态字段
  配不夸大的中文标签（suspected→疑似、confirmed→已确认（限指定条件），未知值原样）。
- **按编号展开（§11.2 #14）**：内容中出现的记录编号（A-001/O-0031/V-003/I-012 等
  前缀+序列形态）渲染为可点击入口；折叠块展开入口；手动输入编号展开（空输入本地拦截，
  不发请求）；展开请求携带当前项目 `?project_id=`（B1 实装要求，§11.2 所有读取校验项目
  访问权）；展开结果只读展示（含证据索引等字段），501/错误各自显式呈现。
- **形状防御**：快照信封接受裸信封或 `{snapshot:{…}}` 包装；内容字段兼容
  content/snapshot_content/map（JSON 字符串自动解析）；折叠说明兼容
  folding_notes/folding/folded/omissions/omitted；完全无法识别时显式「快照形状无法识别」。
- **页面契约**：纯 ESM 不引包、不使用浏览器存储、不使用 React 钩子（沿用 A3 的
  「静态头 + React.Component 子类」模式，见 docs/modules/A3.md 偏差 2）、全中文文案、
  内联样式 `--dsw-alias-*` 带回退值、无构建。
