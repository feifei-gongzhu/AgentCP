## 2. 实现范围

- 端点（蓝图 §5 注册表编号）：本页为纯消费端，无自有端点、无 501 桩替换义务
  （蓝图 §9 报告与覆盖度页行的数据来源 #39/#40/#41 归属 F1/F2）。消费面：
  - **#39 GET /reports/vulnerabilities**（F1）：无 id → 摘要列表信封
    （reports[] + summary + note，状态与复核状态分别计数）；`?id=V-xxx` → 单份
    报告详情信封（report 内容对象 + report_meta + current/requested_version +
    history + history_total），`&version=vN` 历史版本读回；
  - **#40 GET /reports/milestones**（F1）：单份阶段报告信封（五分区 +
    coverage 覆盖块 + data_boundary + history），`&version=vN` 历史读回、
    `&refresh=1` 显式生成新版本（按钮「生成新版本（数据截止到当前）」承载，
    F1 设计读取默认不增殖版本）；
  - **#41 GET /metrics**（F2）：随所选项目携带 project_id 读取（F2 支持
    project_id 域参数；与 A3 总览页的无参数全局视图互补），作报告边界的运行
    背景参考（generated_at/scope 数据时刻语义置顶）；
  - **#4 GET /projects**（A1，项目选择器，同 A3/B3/C3/D3/E3 模式）；
  - **#14 GET /records/{id}?project_id=…**（B1，按编号展开——报告内漏洞/资产/
    证据/来源与后续意图/覆盖块对象编号均为追溯入口）。
- 表/迁移（蓝图 §4）：无（纯前端页，不触碰任何表与迁移）。
- 事件（蓝图 §6 目录）：无。
- 错误码（蓝图 §5.3）：无新增；消费面呈现 F1/F2/B1 回传的既有码
  （NOT_FOUND/BAD_REQUEST/TRUST_DENIED/INTERNAL_ERROR 等）。
- 页面结构（§19 四段逐一落点）：
  - **报告视图（当前 + 历史版本切换，§19 第一段）**：
    - F1 落地信封：漏洞报告列表为各漏洞最新版本摘要卡（id/资产/类别/位置/状态/
      复核/最新版本/历史版本计数/本版变化字段/修订编号/数据截止边界）；单份报告
      经「查看报告详情」按需读取，详情含 §19 最小内容集全量字段（漏洞 ID、资产、
      状态与复核状态、判断条件、支持/反对证据〔成员对象 + 计数 + 内联上限折叠
      说明〕、验证结论〔结果 + 待处理任务〕、限制〔F1 生成的逐条限制清单〕、
      来源意图、后续意图）+ 四向追溯（trace：来源/执行/证据/后续方向，§21 F）+
      修订元数据 + 数据截止边界；版本切换经服务端 version 参数读回历史版本，
      历史版本显式标注「历史版本保留供追溯，当前视图以最新版本为准」；
    - 防御分支（F1 落地前形态，保留）：DDL report_revisions 修订行数组与按主体
      聚合（current + versions/history）双形态本地聚合、本地版本切换、跨页同主体
      版本合并（分页加载新版本时旧当前版自动转历史版本）；
  - **阶段报告（§19 第三段）**：数据截止边界（提交边界 + 生成时间）+
    「边界之后提交的发现不在本版本内，由下一份阶段报告承载；报告生成后探索继续」
    明示；五分区（已确认成果/未确认线索/已完成方向/受阻方向/未覆盖部分）各呈
    摘要行 + 内联明细（对象/数组原样呈现、编号可点击）；exploration_continues
    进行中探索行（生成报告不结束项目，§1）；版本切换（服务端 version）与
    refresh 显式生成；防御分支（修订行/聚合形态）本地版本切换保留；
  - **覆盖缺口（§19 第四段）**：F1 落地信封取阶段报告当前版本 coverage 块——
    未覆盖聚合行（total_assets/assets_without_direction/assets_without_capture）、
    coverage_note、逐资产覆盖记录（维度：资产〔id 可点击 + 类型 + 范围状态 +
    未覆盖标记「无任何测试方向/无任何采集」〕、方向完成情况〔搜集/调查/验证/回访
    四类各自 total/已解决/受阻/进行中/取消〕、采集与观察计数、漏洞发现计数、
    维度：身份或条件〔意图声明与采集观察到的条件，注明不是覆盖声明〕）；
    has_more 折叠说明不静默截断；防御分支取 legacy 聚合条目（dimension 字段
    中英映射 + 未知值原样）；「覆盖度不能简化成『资产挂过一个 Fact 就已测』」
    与「已经执行过某个方向不代表该资产没有其他漏洞」警示常驻；空态显式
    「未提供不代表已覆盖」；覆盖取「当前版本」——切换历史版本不回退覆盖视图；
  - **运行指标（#41）**：数据时刻 + 项目范围置顶、指标对象原样呈现
    （投影滞后/Outbox 积压等用于判断报告视图是否落后于当前数据）、
    「漏洞数量不是唯一健康指标」说明；无项目选择时不请求（等待项目域确定）；
  - **按编号展开（#14）**：整串编号按钮化、嵌入编号的描述文本不整串按钮化
    （不产生可预期的坏入口）；空输入本地拦截；
  - 501 → 「未实现」标注负责模块（F1/F2）、错误 → 错误卡、未知形状 → 显式提示、
    空态显式；全中文文案、不夸大状态；不使用任何浏览器存储；页面只读
    （不提供任何修改报告或漏洞状态的入口，状态变更经验证服务 §8.4）。
