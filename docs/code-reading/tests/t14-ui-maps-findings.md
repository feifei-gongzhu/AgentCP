## ③ 替身 / 隔离 / 时钟手法
- 同为最小 createElement + 同步 setState 宿主（ui-maps:93-133；ui-findings:80-122），绑定真实渲染器（ui-maps:65-82；ui-findings:61-78）；flush 轮数分别为 24/32（ui-maps:135-140；ui-findings:124-129）。
- fakeApi：ui-maps 按「METHOD 基路径」分发、忽略 query，但 handler 可读完整 path 做项目断言（:227-241）；ui-findings 同构（:192-206）。
- 路由桩：ui-maps makeRouter 的 open 只记 hash、不派发 onChange，项目切换测试手工改 projectId/hash 后 fire()（:244-271、:879-881、:1083-1085）；ui-findings 的 open 不更新 params（:208-225）。
- 时钟：两文件均有模块级 Date.now() 夹具；ui-findings JOB_PENDING 的 created_at 由 Date.now()-30min 生成（:279），等待时长断言精确到「30 分 0 秒」（:559）。
- 真实服务：withTestServer 临时 dataDir；写路径用 issueSession 直接签发 worker/planner 会话（ui-maps:308-325、:1171-1208；ui-findings:678-694），经真实 submissions/plan-revisions 写入后读页面，属「真实写端点 + 页面读」集成。

## ④ 断言质量（过拟合 / 放宽 / 同义反复 / 假绿）
- **文件头/用例标题与断言三向漂移**：ui-maps 文件头仍写「资产页五块：站点树…文件及来源」与「订阅边界/resume_cursor」（:8-12）；用例 :633 标题声称 resume_cursor，断言却是 doesNotMatch /resume_cursor/（:645）；用例 :651 标题称五块含站点树与文件及来源，实际只断言三块（:657-670），而 :708-718 又断言两者不渲染。标题不能作为覆盖证据，读测试报告时易误判。
- **快照渲染覆盖不均**：资产页六要素与订阅边界有逐项断言（:639-648）；探索页仅断言 footer 的截止边界/「已加载方向」（:931-932），测试从未断言 SNAP-E-0001、投影范围「折叠边界：提交序号 20」、订阅边界 SUBS-0009、resume_cursor、folding_notes（grep 仅出现在夹具 :469-508）——探索快照头主要分支实际未测。
- **折叠计数/续读名不副实**：资产页断言折叠计数原文（:695）但「展开」只验证导航 hash ?fold_since=12（:696-699），没有带 fold_since 重新挂载验证分组真展开；探索页 folding_notes 无任何断言。发现页折叠计数用交替 /已折叠 3 项|已折叠 2 项/（:406），并再用 if (fold) 包一层（:408-413），前者放宽、后者因 findButton 内部已断言而成为死分支。
- **切 id / 切视图的旧数据路径测不出**：两个文件都用固定 params 一次性 mountDetail（ui-maps:191-194、:722-724；ui-findings:331-338），fake router 的 open 不更新 params（ui-maps:253-258；ui-findings:216）；因此「同一详情实例下 ?id= 变化」「同页 view 变化经 onNav 重载」从未被执行——若页面把初次取数缓存在实例里、或外壳 key 失效，本组测试全部无感（真实保护在 client.js:1081-1090 的 detail key，属 ui-shell 范围）。
- **记录 501 用例空转**：资产页 :791-806 给 record 端点注入 501，但当前实现中 record 状态只被已断链的 renderSources 消费（assets.page.mjs:288/:348-367 与死代码 :776），页面不渲染，故「记录 501 同样不白屏」实际只验证了快照块，属假绿。
- **未知形状名不副实**：ui-findings :474 标题含「形状无法识别」，正文只测空态/无项目/错误（:476-495），无未知形状分支。
- **时钟脆弱**：findings :559 依赖模块加载时 Date.now()-30min 与执行时刻之差，慢 CI 上会从「30 分 0 秒」变「30 分 1 秒」而假红；:727-729 真实服务用 60×30ms 真实等待，无确定性同步点。
- **过拟合/条件分支**：hash 断言固定参数顺序（maps:979 的 ?view=list&id=、:990）；真实服务模板分支 if (hasTemplates) 否则走「未提供」分支（maps:1236-1241），同一次测试随服务端行为摇摆；findings 真实服务用 new RegExp(receipt.ids.v)（:713），弱于精确 chip 断言。
- **正面质量**：URL/路径原样负断言（maps:679-685）、请求复核 P0 守卫断言无 verification-requests/lifecycle（findings:635-638）、P0-4 文本闸（findings:565-578）、JSON 折叠负断言（maps:648）都较硬；findings 投影范围/版本实际值（:511/:555-556）符合「未提供≠不存在」口径。

## ⑤ 覆盖缺口
- 探索页快照头（编号/模式版本/投影范围/订阅边界/resume_cursor/folding_notes）与折叠展开全部无覆盖；view=chain（/lineage）无覆盖。

- 发现页未知形状、确认版本折叠的精确计数、列表与详情共享状态（id 切换）均无覆盖。
- 无 React key 重复、keep-alive/unmount、可访问性（aria-label/focus）断言。
